**本章目标**：让一局能真正分出胜负；实现"黑八指定袋"；结算弹窗、本局计时、本地战绩。

## 1. 什么情况下该打黑八

```js
function isOnEight(player) {
  return !!state.groups[player] && remainingOf(player) === 0;
}
```

"分过组"且"自己组的球一颗不剩"= 该打黑八了。

界面上要跟着提示：

```js
if (isOnEight(state.turn)) {
  statusText = `${nameOf(state.turn)} · 打黑八`;
}
```

## 2. 美式八球要先"指定袋"

中式八球随便哪个袋进黑八都算赢；美式必须先**声明**"我要打这个袋"，进错了袋算输。这是美式八球最容易被忽略的规则。

交互设计：**轻点袋口就算指定**（第 11 章 `pocketAt` 那个 46 像素半径）。

```js
if (state.ruleSet === 'us' && isOnEight(state.turn) && state.calledPocket < 0) {
  toast('黑八阶段请先点击袋口指定目标袋');
  return;                       // 不给打
}
```

指定之后台面上要把那个袋"点亮"，否则玩家会忘了自己点了哪个——项目里是在袋口画一圈黄光。

## 3. 黑八的四种结局

| 情况 | 结果 |
| --- | --- |
| 该打黑八时打进，母球没落袋（美式且袋口对得上） | **赢** |
| 黑八提前进袋（自己还有球没打完） | **输** |
| 美式：进了黑八但袋口不是指定的那个 | **输** |
| 黑八和母球一起进袋 | **输** |

代码思路（`js/rules.js` 的 `endShot` 里）：

```js
const eight = shot.potted.find(p => p.id === 8);
if (eight) {
  const legal = isOnEight(me)                     // 该打了
             && !shot.cuePotted                   // 母球没进
             && (state.ruleSet === 'cn' || eight.pocket === state.calledPocket);
  endGame(legal ? me : 1 - me, legal ? '打进黑八' : '黑八犯规');
  return;
}
```

`endGame(winner, reason)` 负责收尾：

```js
function endGame(winner, reason) {
  state.phase = 'gameover';
  state.gameOver = true;
  state.winner = winner;
  stopClock();                                     // 停表
  updateStatus();
  updateClockUI();

  const spent = formatDurationText(state.clockMs); // "3 分 12 秒"
  showModal(`${nameOf(winner)} 获胜`, `${reason}　本局用时 ${spent}。`, [
    { label: '一键重新开局', onClick: resetGame }
  ]);
}
```

## 4. 本局计时

计时不能直接累加"现在的时间"，因为有暂停（观战暂停、打开玩法卡片）。

项目用的是"两段式记账"：

```js
state.clockMs = 0;        // 已经累计的时长
state.clockSince = 0;     // 这一段从什么时候开始（0 = 暂停中）

function startClock() {
  if (state.clockSince) return;
  state.clockSince = performance.now();
}

function stopClock() {
  if (!state.clockSince) return;
  state.clockMs += performance.now() - state.clockSince;
  state.clockSince = 0;
}

function elapsedMs() {
  return state.clockMs + (state.clockSince ? performance.now() - state.clockSince : 0);
}
```

**好处**：暂停时只是 `clockSince = 0`，恢复时再 `startClock()`，累计值一直在 `clockMs` 里，永远不会算错。

格式化：

```js
function formatClock(ms) {
  const total = Math.floor(ms / 1000);
  const m = String(Math.floor(total / 60)).padStart(2, '0');
  const s = String(total % 60).padStart(2, '0');
  return `${m}:${s}`;                 // 03:12
}
```

`padStart(2, '0')` 把 `3` 变成 `03`，避免出现 `3:5` 这种难看格式。

计时的界面位置也值得说一句：我们试过放页头中间——**面板一展开，它就相对台面偏了**。最后放在台面上方两组球号条中间，跟台面同宽，才永远对齐（第 18 章细讲）。

## 5. 战绩：本地存起来

```js
const RECORDS_KEY = 'eightball.records.v1';

function saveRecord(key, winner) {
  const all = JSON.parse(localStorage.getItem(RECORDS_KEY) || '{}');
  if (!all[key]) all[key] = { p0: 0, p1: 0 };   // 0 胜 / 1 胜 场次
  all[key][winner === 0 ? 'p0' : 'p1'] += 1;
  localStorage.setItem(RECORDS_KEY, JSON.stringify(all));
}
```

`localStorage` 是浏览器给的"小仓库"，**按域名（file:// 就是按文件路径）存字符串，刷新不丢，关掉浏览器也不丢**。

用途分三档 key：

- `local：本地双人` → `{p0, p1}`
- `ai-easy / ai-normal / ai-hard` → 玩家对 AI 的战绩
- **观战局（电脑互打）不记战绩**，因为两边都不是你

`JSON.stringify` / `JSON.parse` 是对象的"打包 / 拆包"，因为 localStorage 只能存字符串。

## 6. 一个重要的取舍：什么时候算"赢"

项目里判定赢的时机是"**黑八落袋的瞬间**"，而不是"等所有球停下"。

因为黑八进袋后其他球还在滚，如果等全停，会出现"我已经赢了但还得等 3 秒"——体验很差。所以 `pocketBall` 里一旦发现是 8 号，且规则上合法，立刻结算。

**这类"规则上应该等、体验上应该快"的取舍，整个项目会遇到很多次。** 原则是：不改判定结果，只改呈现时机。

---

## 7. 坑

1. **`stopClock()` 之后再 `startClock()` 没有重置 `clockSince`**，会重复累加。
2. **结算弹窗没锁输入**，玩家还能拖拽出杆，出现"赢了还能打"。
3. **`localStorage` 存了对象没 `stringify`**，读出来是 `"[object Object]"`。
4. **美式忘了校验指定袋**，玩家随便进黑八就赢，规则形同虚设。

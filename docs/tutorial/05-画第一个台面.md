# 第 5 章 · 画第一个台面

**本章目标**：用 canvas 画出木框、绿色台面、六个袋口；弄懂"坐标从左上角算"这件事。

**开始之前**：第 4 章 —— 知道 `<canvas>`、`getContext('2d')`、画布逻辑尺寸 1120×620。

---

## 1. canvas 的坐标系

画布的左上角是 `(0, 0)`，**x 向右变大，y 向下变大**（跟数学课的 y 轴向上正好相反，这是屏幕的惯例）。

```
(0,0) ──────────────→ x
  │
  │    画布 1120 × 620
  ↓
  y
```

台面在画布中间，四周留 60 的木框：

```js
const VIEW_W = 1120, VIEW_H = 620;   // 画布逻辑尺寸
const RAIL = 60;                     // 木框宽度
const TABLE = { x: 60, y: 60, w: 1000, h: 500 };  // 可击球区域
```

记住这三个数：**60 / 1000 / 500**。整张桌子后面所有计算都围着它们转。

---

## 2. 三个最基础的画笔命令

```js
ctx.fillStyle = '#1f7a52';        // 之后填什么颜色
ctx.fillRect(60, 60, 1000, 500);  // 在 (60,60) 画一个 1000×500 的实心矩形
```

- `fillStyle` 是"颜料桶颜色"，接受 `'#1f7a52'`、`'rgba(0,0,0,.4)'` 这类写法
- `fillRect(x, y, w, h)` 的 `x,y` 是**左上角**，不是中心

所以画台面永远是 `(60, 60, 1000, 500)`：左边留 60 的框，上面留 60 的框。

---

## 3. 圆角矩形要先"描路径"

canvas 没有现成的"圆角矩形"，得自己描：

```js
function roundRect(ctx, x, y, w, h, r) {
  ctx.beginPath();
  ctx.moveTo(x + r, y);                       // 从左上圆角之后开始
  ctx.lineTo(x + w - r, y);                   // 上边
  ctx.arcTo(x + w, y, x + w, y + r, r);       // 右上角
  ctx.lineTo(x + w, y + h - r);               // 右边
  ctx.arcTo(x + w, y + h, x + w - r, y + h, r);
  ctx.lineTo(x + r, y + h);                   // 下边
  ctx.arcTo(x, y + h, x, y + h - r, r);
  ctx.lineTo(x, y + r);                       // 左边
  ctx.arcTo(x, y, x + r, y, r);
  ctx.closePath();
}
```

用法就是：先 `roundRect(...)` 描出形状，再 `ctx.fill()` 上色。

`beginPath` / `moveTo` / `lineTo` / `arcTo` 这一套叫**路径**：像用铅笔画轮廓，最后才填色。**这条规则很重要**——每次画新形状前都要 `beginPath()`，否则 canvas 会把新旧形状连在一起。

## 4. 动手：一张有木框、台面、袋口的桌子

新建 `table.html`，整段贴进去（这次可以复制，因为只是看效果）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>台面</title>
<style>body{margin:0;background:#0a0f14}canvas{display:block;margin:20px auto;max-width:100%}</style>
</head>
<body>
<canvas id="board" width="1120" height="620"></canvas>
<script>
const canvas = document.getElementById('board');
const ctx = canvas.getContext('2d');

const TABLE = { x: 60, y: 60, w: 1000, h: 500 };
const POCKET_R = 32;
const POCKETS = [
  { x: TABLE.x + 6, y: TABLE.y + 6 },
  { x: 560, y: TABLE.y - 4 },
  { x: TABLE.x + TABLE.w - 6, y: TABLE.y + 6 },
  { x: TABLE.x + 6, y: TABLE.y + TABLE.h - 6 },
  { x: 560, y: TABLE.y + TABLE.h + 4 },
  { x: TABLE.x + TABLE.w - 6, y: TABLE.y + TABLE.h - 6 }
];

function roundRect(x, y, w, h, r) {
  ctx.beginPath();
  ctx.moveTo(x + r, y);
  ctx.lineTo(x + w - r, y);
  ctx.arcTo(x + w, y, x + w, y + r, r);
  ctx.lineTo(x + w, y + h - r);
  ctx.arcTo(x + w, y + h, x + w - r, y + h, r);
  ctx.lineTo(x + r, y + h);
  ctx.arcTo(x, y + h, x, y + h - r, r);
  ctx.lineTo(x, y + r);
  ctx.arcTo(x, y, x + r, y, r);
  ctx.closePath();
}

// 1) 木框：整块深棕，圆角 26
const wood = ctx.createLinearGradient(0, 0, 0, 620);
wood.addColorStop(0, '#5d3a20');
wood.addColorStop(1, '#3a2414');
ctx.fillStyle = wood;
roundRect(0, 0, 1120, 620, 26);
ctx.fill();

// 2) 台面：绿色台呢，深一点到浅一点
ctx.fillStyle = '#1f7a52';
roundRect(TABLE.x, TABLE.y, TABLE.w, TABLE.h, 10);
ctx.fill();

// 3) 库边内沿：一圈细高光，让台面看起来有厚度
ctx.strokeStyle = 'rgba(255,255,255,.12)';
ctx.lineWidth = 2;
roundRect(TABLE.x + 3, TABLE.y + 3, TABLE.w - 6, TABLE.h - 6, 9);
ctx.stroke();

// 4) 六个袋口：深色圆
ctx.fillStyle = '#070b0f';
POCKETS.forEach(function (p) {
  ctx.beginPath();
  ctx.arc(p.x, p.y, POCKET_R, 0, Math.PI * 2);
  ctx.fill();
});
</script>
</body>
</html>
```

双击打开。你会看到：棕色木框、绿色台面、一圈细亮边、六个黑洞洞的袋口。

**这就是后面所有画面的底图。** 仓库里 `js/render.js` 的 `drawTable()` 画的是这张的加强版：木框上有木纹渐变、台面上有轻微暗角、袋口外圈还有一圈阴影——但结构完全一样，就是这四步。

## 5. 为什么袋口坐标是"±6""−4"这种怪数字

```js
{ x: TABLE.x + 6, y: TABLE.y + 6 }        // 左上袋，往台面内偏 6
{ x: 560, y: TABLE.y - 4 }                // 中上袋，比台面边缘高出 4
```

袋口**不完全在台面角上**。角袋中心要往内偏一点，中袋要稍微突出台面外一点——这样球滚到袋口时看起来是"掉进去"而不是"卡在边上"。

这种几像素的微调没有任何公式，就是**试出来的**。项目里这 6 个坐标是反复调完定下的，你照抄即可，想改就自己试。

---

## 6. 坑

1. **忘了 `beginPath()`。** 表现是：第二个圆和第一个圆之间多出一条直线、甚至整个填色区域变形。
2. **`arc` 的角度是弧度不是角度。** 一整圈是 `Math.PI * 2`，不是 360。
3. **`fillRect` 的 x/y 是左上角。** 想以 `(560,310)` 为中心画球，得用 `arc(560, 310, r, ...)`（圆心），不是 `fillRect`。

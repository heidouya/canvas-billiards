# 第 2 章 · 认识 JavaScript

**本章目标**：能用"变量"记住数字和文字，能做加减乘除，能打印出来看；知道 `let` 和 `const` 什么时候用哪个。

**开始之前**：第 1 章 —— 能建 `index.html`、能刷新、能打开 Console。

---

## 1. 为什么需要 JavaScript

HTML 只能"摆东西"：这是一段字，那是一个标题。它不会算，也不会动。

台球游戏首先要算：球的坐标、速度、角度、力度是百分之几、还剩几颗球……这些都得有个东西来算。浏览器里干这件事的语言就是 **JavaScript**（简称 JS）。

一句话：**HTML 是骨架，CSS 是皮肤，JS 是肌肉和大脑。**

---

## 2. 把 JS 放进页面

在 `index.html` 的 `</body>` 之前插入：

```html
<script>
  console.log('JS 开始工作');
</script>
```

保存刷新，Console 里应该出现这句话。所有 JS 代码都写在 `<script>` 里面。

（真实项目里我们不会把几千行 JS 塞进 HTML，而是拆成 `js/xxx.js` 文件再引用，第 4 章讲。）

---

## 3. 变量：给数字起个名字

台球桌上一颗球的坐标是固定的两个数字。直接写数字，你三天后就不知道 `310` 是什么了：

```html
<script>
  console.log(260, 310);
</script>
```

给它们起名字：

```js
let cueX = 260;   // 母球的横坐标
let cueY = 310;   // 母球的纵坐标
```

`let` 表示"我要新建一个变量"，`cueX` 是名字，`260` 是值。

**变量就像贴标签的盒子**：你把 260 放进叫 cueX 的盒子，以后说 cueX，指的就是 260。

改一改盒子里的东西：

```js
cueX = 300;              // 直接赋值
cueX = cueX + 40;        // 取出旧值加 40，再放回去 → 340
```

### let 还是 const

如果你确定这个值**不打算再改**，用 `const`：

```js
const BALL_R = 14;       // 球半径，永远 14
let power = 0;           // 力度，会从 0 变到 1
```

记不住规则就用这句口诀：**"默认写 const，需要改才写 let"**。项目里所有常量（`VIEW_W`、`MAX_SPEED`、`BALL_R`）都是 `const`，因为它们描述的是规则，不该被中途改掉。

## 4. 数字：JS 会算数

```js
const tableW = 1000;
const ballR = 14;
console.log(tableW - ballR * 2);   // 972
```

`*` `/` `+` `-` 就是乘除加减，括号优先，跟小学数学一样。

几个游戏里天天用的：

```js
const power = 0.71;
console.log(power * 100);                  // 71  → 界面上的 71%
console.log(Math.round(power * 100));      // 71  → 四舍五入成整数
console.log(Math.hypot(3, 4));             // 5   → 直角三角形斜边，算距离用
console.log(Math.min(1, 2.5));             // 1   → 取小的那个
console.log(Math.max(0, -3));              // 0   → 取大的那个
```

`Math.xxx` 是 JS 自带的数学工具盒，`hypot` 算距离、`round` 四舍五入、`min`/`max` 夹范围。**后面物理部分几乎每一行都在用它们。**

---

## 5. 字符串：一段文字

文字用引号包起来，单双引号都行：

```js
const name = '玩家 1';
const msg = '轮到 ' + name + ' 击球';
console.log(msg);                 // 轮到 玩家 1 击球
```

用 `+` 把文字和变量拼起来，这叫**拼接**。还有个更省事的写法，叫模板字符串，用反引号（键盘左上角 ` 那个键）：

```js
const player = 1;
console.log(`轮到玩家 ${player} 击球`);   // 轮到玩家 1 击球
```

`${...}` 里面的东西会被算出来插进文字里。项目里所有提示语都是这么拼的。

---

## 6. 注释：写给人看的话

```js
// 两个斜杠，这一行后面都是给人看的，JS 不管

/*
  多行注释
  写在这里也不会被执行
*/
```

**好注释写"为什么"，不写"是什么"。**

```js
const MAX_DRAG = 84;   // ❌ 力度上限
const MAX_DRAG = 84;   // ✅ 拖 84 个逻辑像素就算满力，再远也是 100%
```

## 7. 用它写点真东西

现在你就能算出游戏里两个真实数值了：

```js
const VIEW_W = 1120;    // 逻辑画布宽
const RAIL = 60;        // 木框宽度
const tableX = RAIL;                        // 台面左边界
const tableW = VIEW_W - RAIL * 2;           // 台面宽度 = 1120 - 120 = 1000
const tableCenterX = tableX + tableW / 2;   // 台面中心 = 60 + 500 = 560

console.log(tableW, tableCenterX);          // 1000 560
```

这就是项目 `js/config.js` 前 16 行的内容——你已经会写它了。

---

## 8. 三个新手必踩的坑

1. **中文标点。** `let x = 1；` 那个`；`是中文分号，直接语法错误。看报错里如果说 `Invalid or unexpected token`，先检查标点。
2. **名字拼错 / 大小写。** `cueX` 和 `cuex` 是两个不同的变量，JS 区分大小写。报 `xxx is not defined` 先回头找拼写。
3. **变量名不能以数字开头**，也不能有空格和减号：`ball1` 可以，`1ball`、`ball-1` 不行。

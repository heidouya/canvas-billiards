# 第 1 章 · 先跑起来

**本章目标**：写出你的第一个网页文件，双击就能在浏览器里打开；学会改一行、刷新看变化；学会打开浏览器控制台读报错。

**开始之前**：会用鼠标新建文件夹，会用浏览器。别的都不需要。

---

## 1. 网页到底是什么

说白了，网页就是**一个文本文件**。你用记事本写文字，浏览器把它读进去，按规则画成彩色画面。

没有服务器、没有安装、没有"编译"这一步。你在文件夹里放一个 `index.html`，双击它，浏览器就把这个文件当网页打开——地址栏会变成 `file:///.../index.html`。

这就是"纯前端"的好处：**你的电脑就是服务器**。后面我们整个台球游戏都靠这一点，180 行 HTML + 一堆 js，双击即玩，断网也能玩。

---

## 2. 动手：第一个文件

新建一个文件夹，比如 `D:\my-pool`。在它里面新建文件 `index.html`（注意后缀必须是 `.html`，不是 `.txt`）。

用记事本打开，一字不差敲进下面这段：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>我的台球</title>
</head>
<body>
  <h1>你好，台球</h1>
  <p>这是我做的第一个网页。</p>
</body>
</html>
```

保存（`Ctrl + S`），然后双击 `index.html`。

你应该看到一个黑色标题"你好，台球"和一行小字。

### 每一行在说什么

| 这一行 | 意思 |
| --- | --- |
| `<!DOCTYPE html>` | 告诉浏览器："这是新式网页"，照标准画，别用老规矩 |
| `<html lang="zh-CN">` | 整份文件的根，语言是简体中文 |
| `<head>` | 给浏览器看的"说明区"，里面东西不显示在页面上 |
| `<meta charset="utf-8">` | 文件是 UTF-8 编码。**这行不能少**，少了中文会变乱码 |
| `<title>` | 浏览器标签页上显示的名字 |
| `<body>` | 真正显示给人看的内容 |
| `<h1>` / `<p>` | 一级标题 / 段落。像 Word 里的大标题和正文 |

`<xxx>内容</xxx>` 这种成对尖括号的东西叫**标签**。标签负责"这是什么"，不负责"长什么样"——长什么样是第 4 章要讲的 CSS。

---

## 3. 改一行，刷新看看

把 `<h1>你好，台球</h1>` 改成：

```html
<h1>我要做一款台球游戏</h1>
```

保存，回到浏览器，按 `Ctrl + R`（或点刷新按钮）。

文字变了，说明这一整套流程通了：**改文件 → 保存 → 刷新 → 看效果**。接下来 22 章，你要重复这个动作几百次。

---

## 4. 学会打开"控制台"

这一步很关键，学会它，你后面能自己修一半的错。

在页面上按 `F12`（笔记本可能是 `Fn + F12`），会出现一个开发者工具面板。找到 **Console（控制台）** 这一栏，点开。

你会看到一片空白，可能带个 `>` 符号——那是等你输入命令的地方。

先不输入命令。我们让代码主动往这里"说话"：在 `<body>` 里加一行：

```html
<script>
  console.log('程序跑起来了');
</script>
```

保存、刷新，再回 Console 看，多了一行 `程序跑起来了`。

`console.log(...)` 就是"把括号里的东西打印到控制台"。**它不会显示在页面上，只给开发者看**——所以它是排查问题最好用的工具。第 2 章我们会一直用它。

### 故意造个错

把上面那行改成（故意少一个右括号）：

```html
<script>
  console.log('程序跑起来了';
</script>
```

保存、刷新。页面可能还正常，但 Console 里多了一行**红字**，大致长这样：

```
Uncaught SyntaxError: missing ) after argument list
```

意思是"语法错误：参数后面缺了一个右括号"。它还会告诉你**在第几行**。

> 新手最常见的两个报错：
> - `SyntaxError: missing ) after argument list` —— 括号没配对
> - `ReferenceError: xxx is not defined` —— 用了一个没定义过的名字（拼错了，或者还没写）

**看到红字不要慌，先读第一句，它通常直接说了原因。** 你刚才故意犯的错，就是以后每天都会遇到的东西。

---

## 5. 这一章最容易踩的四个坑

1. **文件存成了 `index.html.txt`。** Windows 默认"隐藏已知文件类型的扩展名"，你看着是 `index.html`，实际是 txt。解决：在资源管理器里勾上"文件扩展名"，或右键看属性里的类型。
2. **用中文标点。** `（`、`“`、`：`、`；` 全都不行，代码里只能用英文半角 `(`、`"`、`:`、`;`。
3. **改完没保存就刷新。** 记事本按 `Ctrl + S` 才算保存。
4. **双击打开的是旧文件。** 你可能建了两个 `index.html`（一个在桌面一个在文件夹里）。看浏览器地址栏的路径。

---

## 6. 动手练习

1. 把标签页标题（`<title>`）改成你的名字。
2. 在页面上再加两行段落，写你今天想做的游戏。
3. 把 `console.log('程序跑起来了')` 里的文字换成中文，看看控制台显示得对不对（这能验证 UTF-8 那行生效了）。
4. 故意把 `<h1>` 的 `>` 删掉，看会发生什么。再改回来。

做完这四个，你已经具备了"自己动手改、自己看结果"的能力。下一章开始学 JavaScript——网页里真正会"算"的那部分语言。

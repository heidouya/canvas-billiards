# 第 16 章 · AI 对手

**本章目标**：让电脑会瞄准、会选目标、会"假装"有强有弱；理解"枚举 + 试算 + 加误差"这套最朴素也最有效的 AI 做法。

**开始之前**：第 9 章（碰撞）、第 13 章（射线求交）、第 14 章（规则）。

---

## 1. 电脑打球要解决三件事

1. **打哪颗球**：自己的目标球里选一颗
2. **往哪个方向打**：要把目标球送进袋，母球得先撞到它的"幽灵球位"（ghost ball）
3. **用多大力**：够滚到袋口、又不至于弹回来

---

## 2. 幽灵球位：把"进球"变成"直线"

想用母球把目标球推进袋，母球撞到目标球的**瞬间**，三者的位置是固定的：

```
   母球 ──→  ◎ 幽灵球位        ● 目标球 ──→ 袋口
                 ╲                    ╱
                  ╲    连线必须共线   ╱
```

"幽灵球位"就是一个假想的球：它位于"目标球 → 袋口"的反向延长线上，离目标球 28（两倍半径）。

```js
function ghostPoint(target, pocket) {
  const dx = target.x - pocket.x;
  const dy = target.y - pocket.y;
  const d = Math.hypot(dx, dy);
  return {
    x: target.x + dx / d * BALL_R * 2,   // 从目标球往"远离袋口"的方向退 28
    y: target.y + dy / d * BALL_R * 2
  };
}
```

母球要做的就是**朝这个幽灵球位直线打过去**：

```js
const aimDir = {
  x: ghost.x - cue.x,
  y: ghost.y - cue.y
};
// 归一化
```

所以 AI 的核心就变成了："**对每一颗目标球 × 每一个袋口，都算一次幽灵球位，检查这条路通不通。**"

---

## 3. 判断"这条路通不通"

两条检查：

1. **幽灵球位能不能打到**：从母球到幽灵球位的连线上，有没有别的球挡着
2. **目标球到袋口通不通**：目标球滚向袋口的路上，有没有别的球

用第 13 章的射线求交：

```js
function pathClear(px, py, dx, dy, ignoreIds, maxLen) {
  // 沿射线走，看有没有球在 maxLen 距离内被碰到
  const hit = rayHitBallAny(px, py, dx, dy, ignoreIds);
  return !hit || hit.dist > maxLen;
}
```

`ignoreIds` 要把"母球自己"和"目标球自己"排除掉，否则它们会挡住自己的路。

---

## 4. 打分：选最好的一条

每个候选线路算出"好不好"：

```js
score = 100
      - 母球到幽灵球位的距离 * 0.02      // 太远不稳
      - 目标球到袋口的距离 * 0.02        // 太远不稳
      - 入射角偏差 * 权重                // 角度越刁越难
      + (袋口是角袋 ? 8 : 0);            // 角袋更好进（中袋两侧有库）
```

**这个打分函数是拍脑袋写的第一版，然后靠试玩调。** 不要指望一次写对——AI 的手感也是调出来的。

选最高分：

```js
let best = null;
candidates.forEach(function (c) {
  if (!best || c.score > best.score) best = c;
});
```

## 5. 三档难度：不是"更聪明"，而是"更准"

关键认知：**让 AI 变强，最有效的办法不是让它算得更复杂，而是减少它的误差。**

```js
const LEVELS = {
  easy:   { angleErr: 2.2, powerErr: 0.10, planRate: 0.85 },
  normal: { angleErr: 1.0, powerErr: 0.05, planRate: 0.95 },
  hard:   { angleErr: 0.6, powerErr: 0.03, planRate: 1.00 }
};
```

- `angleErr`：方向抖多少度（2.2° 在 1 米外偏 4 厘米，足以打不进）
- `powerErr`：力度抖多少
- `planRate`：多大比例会"认真规划"，剩下的随机瞎打

```js
const err = (Math.random() * 2 - 1) * level.angleErr;   // -err ~ +err 随机
const angle = Math.atan2(dir.y, dir.x) + err * Math.PI / 180;
```

**"简单"档的 AI 不是傻，是手抖。** 玩家感受到的是"它会打，但经常打偏"——这比"它乱打"更像人。

---

## 6. 力度怎么给

一个够用的估算：距离越远，需要越大力度。

```js
const needDist = dist(cue.x, cue.y, ghost.x, ghost.y) + dist(target.x, target.y, pocket.x, pocket.y);
const power = clamp(needDist / 1400, 0.28, 0.92) * (1 + powerErrRandom);
```

`0.28` 是下限（太轻推不动），`0.92` 是上限（满力容易飞）。实际项目里还会根据"目标球离袋口多近"微调。

---

## 7. 出杆的时机：要让人看得见

AI 不能"瞬间出杆"，否则玩家不知道发生了什么。所以用定时器：

```js
setTimeout(function () {
  shoot(aiPower);
}, aiThinkMs);      // 简单 900ms、普通 1100ms、困难 1300ms 左右
```

还要在 AI 思考期间**锁住玩家输入**：

```js
function canControl() {
  if (isAIPlayer(state.turn)) return false;   // 电脑回合，玩家不能操作
  ...
}
```

`isAIPlayer(turn)` 在三种模式下含义不同：

```js
function isAIPlayer(player) {
  if (state.mode === 'auto') return true;                 // 电脑互打：两边都是
  if (state.mode === 'ai' && player === 1) return true;   // 人机：玩家 0，电脑 1
  return false;                                            // 本地双人：都不是
}
```

## 8. 一个必须处理的特殊情况

**AI 无球可打**（比如自己组全进袋了但忘了打黑八、或者全部被挡住）。这时不能让 AI 卡死，要退化处理：随机方向 + 中等力度，至少能打出去一杆。

```js
if (!best) {
  return { dir: randomDir(), power: 0.5, target: null };
}
```

**"永远要有兜底动作"是 AI 代码的第一原则**，否则一个小概率情况就让整局卡住。

---

## 9. 坑

1. **忘了排除自己**：AI 检查路线时没排除母球，永远觉得"路被挡住"。
2. **计算太慢**：每帧算 15×6 条路线会卡。项目里只在"轮到我出杆时算一次"，不在每帧算。
3. **误差加在"最终速度"上而不是"方向上"**：看起来像力度不对，实际是方向不准，手感会很怪。
4. **思考时间固定**：困难档也 200ms 出杆，玩家来不及看清球路，体验像"作弊"。

---

## 10. 练习

1. 让 AI 只打"最近的那颗球 + 最近的袋口"，先跑通流程。
2. 加上"路线是否被挡"的检查，看 AI 是不是不再往球堆里瞎打了。
3. 把 `angleErr` 改成 `0`，AI 几乎不失误——这就是"困难档很难赢"的原因。
4. 让 AI 打一杆后打印它选的目标球和袋口，验证选择是否合理。

# 第 14 章 · 游戏状态与规则

**本章目标**：用一个 `state` 对象管住整局游戏；把"一杆"从出杆到结算走完整流程；实现分球组、续杆、犯规、自由球。

**开始之前**：第 8–13 章。现在球能动、能撞、能进袋，但你还没有"一轮比赛"。

---

## 1. 先把"现在的局面"装进一个对象

```js
const state = {
  mode: 'ai',            // 'local' 本地双人 / 'ai' 人机 / 'auto' 电脑互打
  ruleSet: 'cn',         // 'cn' 中式 / 'us' 美式
  balls: [],             // 16 个球对象，[0] 是母球
  turn: 0,               // 当前击球方：0 / 1
  groups: [null, null],  // 分球组：'solid' / 'stripe' / null 未定
  phase: 'aim',          // 当前阶段，见下
  power: 0,              // 力度 0~1
  aimDir: { x: 1, y: 0 },
  aiming: false,         // 是否正在拖拽瞄准
  dragMode: null,        // 'aim' | 'place' | null
  ballInHand: false,     // 是否手里拿球
  breakDone: false,      // 开球是否已完成
  shot: null,            // 当前这一杆的记录
  lastFoul: null,        // 上一次犯规原因（给界面显示）
  calledPocket: -1,      // 美式黑八指定的袋口
  clockMs: 0             // 本局已用时间（毫秒）
};
```

**`state` 是整个游戏唯一的"真相来源"。** 画面、规则、AI 全都读它；任何变化都写回它。这样出 bug 时你只需要问一个问题：**"state 的哪个字段不对？"**

---

## 2. 阶段（phase）：一局游戏有几个"状态"

```
        ┌──────────── 玩家瞄准 ────────────┐
        ↓                                  │
   phase='aim' ──出杆──→ 'shooting' ──球停──→ 结算
        ↑                                  │
        │                                  ├─ 该换人 ──→ 'aim'
        │                                  ├─ 未定组进球 ─→ 'groupChoice'
        └────────── 关掉选择弹窗 ←──────────┘
                                           └─ 黑八分出胜负 ─→ 'gameover'
```

代码里用一个字符串表示：

```js
state.phase = 'aim';        // 可以瞄准、可以拖拽
state.phase = 'shooting';   // 球在滚，锁住输入
state.phase = 'groupChoice';// 等玩家选球组
state.phase = 'replay';     // 回放中
state.phase = 'gameover';   // 已分出胜负
```

输入层只看一个判断：

```js
function canControl() {
  if (state.modalOpen || state.gameOver || state.locked) return false;
  if (state.phase !== 'aim') return false;
  if (isAIPlayer(state.turn)) return false;
  return true;
}
```

**"能不能操作"集中在一个函数里判断**，而不是到处写 `if`。这是让代码不乱的关键。

## 3. 一杆的开始：`shoot(power)`

出杆时要做三件事：

```js
function shoot(power) {
  const cue = cueBall();

  // 1) 给母球速度
  const speed = Math.max(MIN_SHOT_SPEED, MAX_SPEED * power);
  cue.vx = state.aimDir.x * speed;
  cue.vy = state.aimDir.y * speed;

  // 2) 建一份"这一杆的记录"，规则结算时要用
  state.shot = {
    firstHit: null,        // 母球第一次碰到的球号
    potted: [],            // 这一杆进了哪些球 [{id, pocket}]
    cuePotted: false,      // 母球是否落袋
    eightPocket: null,     // 黑八进了哪个袋
    cushionBalls: [],      // 碰过库的目标球（开球有效性判定用）
    targetKind: targetKind(state.turn),  // 这杆该打什么：solid/stripe/eight/open
    isBreak: !state.breakDone
  };

  // 3) 切阶段、清临时状态
  state.phase = 'shooting';
  state.aiming = false;
  state.ballInHand = false;
  state.power = 0;
  state.lastFoul = null;
}
```

**为什么要建 `state.shot`？** 因为物理过程是"异步"的：球滚 2 秒才停。这 2 秒里发生的所有事（碰到谁、进了谁）都得先记下来，等球全停了再统一判。

这就是游戏开发里常说的"**事件记录 → 事后结算**"。

## 4. 球全停了才结算

```js
function allStopped() {
  for (const b of state.balls) {
    if (b.active && (b.vx !== 0 || b.vy !== 0)) return false;
  }
  return true;
}
```

主循环里：

```js
if (state.phase === 'shooting' && allStopped()) {
  endShot();
}
```

`endShot()` 是规则的核心，简化版长这样：

```js
function endShot() {
  const me = state.turn;
  const shot = state.shot;
  state.shot = null;
  state.phase = 'aim';
  state.breakDone = true;

  // ---- 判定犯规 ----
  let foul = null;
  if (shot.cuePotted) foul = '母球落袋';
  else if (shot.firstHit === null) foul = '空杆（没碰到任何球）';
  else if (!isLegalFirstHit(shot.firstHit, me)) foul = '先碰到了不该碰的球';

  if (foul) {
    state.lastFoul = foul;
    state.turn = 1 - me;          // 换人
    state.ballInHand = true;      // 对方拿到手中球
    return;
  }

  // ---- 没犯规：看进球 ----
  if (shot.potted.length === 0) {
    state.turn = 1 - me;          // 没进球，换人
    return;
  }

  // 进了球：分组、续杆、黑八判定……（下一章细讲）
}
```

真实代码在 `js/rules.js` 的 `endShot()`，有 200 多行——因为要处理"开球没碰到库"、"8 号提前落袋"、"打进对方球"等等一堆分支。**结构就是上面这个：先判犯规，再判进球，最后判胜负。**

## 5. 分球组：第一次进球定终身

开球后，台面是"开放的"（`groups = [null, null]`），谁先进球，那一类就归谁：

```js
function ballKind(id) {
  if (id === 8) return 'eight';
  return id < 8 ? 'solid' : 'stripe';     // 1-7 纯色，9-15 花色
}

function assignGroups(player, kind) {
  state.groups[player] = kind;
  state.groups[1 - player] = (kind === 'solid') ? 'stripe' : 'solid';
}
```

如果一杆同时进了纯色和花色（或者开球时进了一堆），就弹一个"请选择你的球组"：

```js
state.phase = 'groupChoice';
```

玩家点了哪一组，就调 `assignGroups`。

> 项目里的做法是：开球进袋不分组（开球那杆不算定组），只有开球之后的第一次进球才定组。这是中式/美式共同的常见规则简化。

## 6. 该打哪颗球：`targetKind`

```js
function targetKind(player) {
  if (!state.groups[player]) return 'open';              // 还没分组
  return remainingOf(player) === 0 ? 'eight'            // 自己的球打完了
                                  : state.groups[player];
}
```

`remainingOf` 数一下自己组还剩几颗：

```js
function remainingOf(player) {
  const g = state.groups[player];
  if (!g) return 99;
  let n = 0;
  for (const b of state.balls) {
    if (b.active && b.id !== 0 && ballKind(b.id) === g) n++;
  }
  return n;
}
```

`remainingOf(player) === 0` 就意味着"该打黑八了"，第 15 章接着讲。

## 7. 两套规则的四个差异

中式八球和美式八球 95% 一样，只有四处不同：

| 差异 | 中式 | 美式 |
| --- | --- | --- |
| 袋口 | 紧（判定半径 23） | 松（26） |
| 犯规后自由球 | 全台可放 | 只能放开球区 |
| 开球有效性 | 相对宽松 | 要求更严（碰库、进球数） |
| 黑八 | 任意袋都算赢 | **必须先点袋指定** |

切换规则只要改几个变量：

```js
function applyRuleSet(rule) {
  state.ruleSet = rule;
  POCKET_R = (rule === 'cn') ? POCKET_R_CN : POCKET_R_US;
  CAPTURE_R = (rule === 'cn') ? CAPTURE_R_CN : CAPTURE_R_US;
}
```

**注意：`POCKET_R` 和 `CAPTURE_R` 是 `let` 而不是 `const`**，因为它们要随规则变——这就是第 2 章"默认 const，需要改才 let"的实际应用。

## 8. 坑

1. **在物理过程中改 `turn`。** 球还在滚就换人，界面会闪；必须等 `allStopped()`。
2. **`state.shot` 忘了清空。** 下一杆会继承上一杆的 `potted`，出现"上一杆进的球算这一杆"的怪事。
3. **犯规判定顺序错。** 母球落袋优先于"没碰到球"，否则母球进袋会被判成空杆，提示文案就错了。
4. **分组后没检查"先碰对组"。** 玩家拿纯色先碰花色，必须犯规，否则规则就是假的。

# 第 17 章 · 回放与电脑互打

**本章目标**：把上一杆的完整运动录制下来、随时重播；让两台电脑对打，还能暂停观战。

**开始之前**：第 16 章 —— AI 会打球了。

---

## 1. 回放的思路：录"位置"，不录"事件"

有两种录法：

- 录事件（"第 0.3 秒 A 撞了 B"）→ 回放时要重算物理，可能和当时不一致
- **录位置**（每 1/60 秒记下 16 颗球的坐标）→ 回放时只管插值画出来，绝对一致

我们选第二种。**简单、可靠、不会两遍算出不同结果。**

### 开始录

```js
function startRecording() {
  state.replayFrames = [];
  state.replayRecording = true;
}
```

### 每帧采样

```js
const REPLAY_INTERVAL = 1 / 60;

function sampleReplay(dt) {
  if (!state.replayRecording) return;
  replayAcc += dt;
  if (replayAcc < REPLAY_INTERVAL) return;
  replayAcc = 0;

  // 只存"还活着"的球：id + 坐标
  state.replayFrames.push(
    state.balls.map(function (b) {
      return { id: b.id, x: b.x, y: b.y, active: b.active };
    })
  );
}
```

一杆大概 3–5 秒，60fps，就是 200–300 帧，每帧 16 个球 → 几千个数字。**内存完全不是问题。**

### 结束录

```js
function finishRecording() {
  state.replayRecording = false;
  state.replayReady = state.replayFrames.length > 6;   // 太短的杆不值得回放
}
```

## 2. 回放时的插值

回放帧率可能和当前屏幕刷新率不同，所以要在两帧之间"插值"：

```js
function replayAt(t) {         // t = 0 ~ 1 的播放进度
  const frames = state.replayFrames;
  const pos = t * (frames.length - 1);
  const i = Math.floor(pos);
  const k = pos - i;                       // 0~1 之间的小数部分
  const a = frames[i];
  const b = frames[Math.min(i + 1, frames.length - 1)];

  return a.map(function (ball, idx) {
    const nb = b[idx];
    return {
      id: ball.id,
      x: ball.x + (nb.x - ball.x) * k,     // 线性插值
      y: ball.y + (nb.y - ball.y) * k,
      active: ball.active && nb.active
    };
  });
}
```

**线性插值就够**：球速快时 60fps 采样的两帧离得很近，中间补一条直线看不出来。

播放：

```js
state.phase = 'replay';
let t = 0;
function replayFrame(dt) {
  t += dt / 3.2;                       // 3.2 秒播完
  if (t >= 1) { t = 1; endReplay(); }
  renderBalls(replayAt(t));
}
```

`endReplay()` 把 `state.phase` 改回 `'aim'`，回到正常游戏。

## 3. 电脑互打：让两边都是 AI

模式切换只改一个字段：

```js
state.mode = 'auto';
```

然后 `isAIPlayer()` 对两边都返回 `true`（第 16 章那个函数）。AI 的调度逻辑里有个驱动：

```js
function maybeRunAI() {
  if (state.phase !== 'aim') return;
  if (!isAIPlayer(state.turn)) return;
  if (state.autoPaused) return;         // 暂停观战时不动
  aiShot(state.turn);
}
```

主循环里每帧检查一次。AI 出杆后会经过"球滚动 → 结算 → 换人 → 又是 AI"，于是自己滚起来。

**注意电脑互打时胜负不记战绩**：两边都不是玩家，记进去没意义。

```js
if (state.mode !== 'auto') saveRecord(key, winner);
```

## 4. 暂停观战：连计时一起停

```js
state.autoPaused = true;
stopClock();                            // 表停
el('btnAutoPause').textContent = '继续观战';
```

恢复：

```js
state.autoPaused = false;
startClock();                           // 表继续
```

暂停时数字要变个颜色，让玩家知道"不是卡了，是我按了暂停"：

```js
clockTextEl.dataset.paused = state.autoPaused ? '1' : '0';
```

```css
.rack-clock[data-paused="1"] { color: #f0a85e; }
```

**这类"状态可视化"很重要**：用户看到的必须和系统实际状态一致，否则就会以为程序坏了。

## 5. 观战的额外处理

电脑互打时，玩家不该能操作台面：

```js
if (state.mode === 'auto') {
  // 台面上不画力度药丸、不响"请输入力度"之类的提示
}
```

同时也不该弹"该你打了"的引导语。项目里所有这类文案都走 `nameOf()`：

```js
function nameOf(player) {
  if (state.mode === 'auto') return player === 0 ? '电脑 1' : '电脑 2';
  if (player === 1 && state.mode === 'ai') return '电脑';
  return player === 0 ? '玩家 1' : '玩家 2';
}
```

**一个函数决定所有称呼**，改文案只改一处。

---

## 6. 坑

1. **回放期间还能瞄准**：`canControl()` 必须检查 `phase === 'aim'`（第 14 章已有）。
2. **回放帧里存了整个球对象**（含速度），内存翻倍且没必要。只存 `id/x/y/active`。
3. **观战暂停了但 AI 还在算**：`maybeRunAI` 里必须检查 `autoPaused`。
4. **`setTimeout` 的 AI 出杆在暂停后仍然执行**：要清掉定时器或在回调里再检查一次状态。

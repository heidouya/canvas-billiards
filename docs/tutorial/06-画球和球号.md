# 第 6 章 · 画球和球号

**本章目标**：用半径 14 的圆画出母球和 15 颗彩球；做出球的高光、花色球的色带、白圈里的编号；用循环把 16 颗球一次画完。

**开始之前**：第 5 章 —— 会画圆角矩形、会画圆、知道 `beginPath`。

---

## 1. 一颗球由几层画出来

真球看起来是立体的，其实是用 3–4 层"假装的"：

```
第 1 层  球底的阴影（椭圆的暗影，落在台面上）
第 2 层  球体本身（圆形 + 径向渐变，左上亮右下暗）
第 3 层  号码底盘（白色小圆）
第 4 层  号码数字
```

高光的秘密只有一句：**径向渐变的圆心偏向左上角**。

```js
function drawBall(ctx, x, y, color) {
  // 1) 落在台面上的影子
  ctx.beginPath();
  ctx.ellipse(x + 2, y + 3, 13, 9, 0, 0, Math.PI * 2);
  ctx.fillStyle = 'rgba(0,0,0,.35)';
  ctx.fill();

  // 2) 球体：高光在左上
  const g = ctx.createRadialGradient(x - 5, y - 6, 2, x, y, 14);
  g.addColorStop(0, lighten(color, 0.55));   // 亮面
  g.addColorStop(1, darken(color, 0.35));    // 暗面
  ctx.beginPath();
  ctx.arc(x, y, 14, 0, Math.PI * 2);
  ctx.fillStyle = g;
  ctx.fill();
}
```

`createRadialGradient(内圈x, 内圈y, 内圈r, 外圈x, 外圈y, 外圈r)`：光从左上 `(x-5, y-6)` 打进，中心在外缘。

`lighten` / `darken` 在项目 `js/util.js` 里，作用是把 `'#f2c53d'` 这种十六进制颜色调亮或调暗一点。你也可以偷懒用 `'#ffffff33'` 这种半透明白盖一层。

## 2. 花色球：白底 + 一条色带

1–7 是纯色球，整颗都是颜色；9–15 是**花色球**：白球身，中间一条彩色带。

画法：先画一颗白球，再画一条矩形色带，但**只保留落在圆内的部分**：

```js
function drawStripeBall(ctx, x, y, color) {
  // 白底
  drawBall(ctx, x, y, '#f4f2ea');

  // 色带：用一个矩形，宽度撑满，高度约 16
  ctx.save();                       // 记住当前状态
  ctx.beginPath();
  ctx.arc(x, y, 14, 0, Math.PI * 2); // 剪裁范围 = 这个圆
  ctx.clip();                       // 之后画的东西只留圆内

  ctx.fillStyle = color;
  ctx.fillRect(x - 15, y - 8, 30, 16);   // 横贯整颗球的色带

  ctx.restore();                    // 恢复，取消剪裁
}
```

`save()` / `clip()` / `restore()` 是一组：**save 记住当前裁剪区域和样式，clip 设置"只允许画在这个形状里"，restore 撤回。** 忘了 `restore` 会导致后面所有东西都被裁掉，这是新手常见事故。

## 3. 号码：白圆 + 数字

```js
ctx.save();
ctx.beginPath();
ctx.arc(x, y, 6.2, 0, Math.PI * 2);
ctx.fillStyle = '#fbfbf8';
ctx.fill();

ctx.fillStyle = '#111';
ctx.font = 'bold 8px sans-serif';
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText(id, x, y + 0.5);
ctx.restore();
```

`textAlign = 'center'` + `textBaseline = 'middle'` 让文字以 `(x, y)` 为**中心**，否则默认是从左往右、从上往下贴着写，会明显偏右下。

母球（`id === 0`）不画号码和色带。

## 4. 16 颗球，用循环一次画完

数据先摆好（一段简化版的摆球）：

```js
const BALL_R = 14;
const RACK_X = 794;   // 球堆顶点，考究一点叫"置球点"

const balls = [{ id: 0, x: 260, y: 310, active: true }];   // 母球永远第一个

// 三角堆：4 行，每行 1/2/3/4 颗
const rows = [[1], [9, 2], [10, 8, 3], [11, 4, 12, 5]];
rows.forEach(function (row, ri) {
  row.forEach(function (id, ci) {
    balls.push({
      id: id,
      x: RACK_X + ri * (BALL_R * 1.75),
      y: 310 + (ci - ri / 2) * (BALL_R * 2.02),
      active: true
    });
  });
});
```

画的时候：

```js
balls.forEach(function (b) {
  if (!b.active) return;            // 已落袋的球不画
  if (b.id === 0) {
    drawBall(ctx, b.x, b.y, '#f8f6ef');       // 母球：纯白
  } else if (b.id < 8) {
    drawBall(ctx, b.x, b.y, BALL_COLORS[b.id]);  // 纯色
    drawNumber(ctx, b.x, b.y, b.id);
  } else {
    drawStripeBall(ctx, b.x, b.y, BALL_COLORS[b.id]);  // 花色
    drawNumber(ctx, b.x, b.y, b.id);
  }
});
```

`BALL_COLORS` 是 `js/config.js` 里那张颜色表：

```js
const BALL_COLORS = {
  1: '#f2c53d', 2: '#2f6dd0', 3: '#d64545', 4: '#7b4bc4',
  5: '#e8853a', 6: '#2f9e57', 7: '#8f2233', 8: '#1b1b1b',
  9: '#f2c53d', 10: '#2f6dd0', 11: '#d64545', 12: '#7b4bc4',
  13: '#e8853a', 14: '#2f9e57', 15: '#8f2233'
};
```

**9–15 和 1–7 用同一套色**，这不是偷懒——真实台球就是这样，9 号球和 1 号球同色，靠"花色"区分。

## 5. 两个约定，整个项目都靠它们

1. **`state.balls[0]` 永远是母球。** 所有"找母球"的代码都是 `state.balls[0]`，项目里还包了个函数 `cueBall()`。
2. **球是数据，画是另一回事。** `balls` 数组里只有 `x / y / id / active` 这些数字，没有任何"怎么画"的信息。`render.js` 读这些数字去画。

这条约定意义很大：物理只需要改 `x / y`，画面自动跟上；改球的样式不影响物理。第 8 章开始动起来时你就体会到好处了。

---

## 6. 坑

1. **`active = false` 的球忘了跳过。** 表现：球落袋后还在原地呆着，还叠一颗。
2. **`clip` 之后没 `restore`。** 表现：画完第一颗花色球，后面所有球都被裁成一小块。养成**"clip 必配 save/restore"**的习惯。
3. **`font` 大小跟着屏幕变。** 我们固定逻辑尺寸 1120，字号写死 8px 就够。等你做第 7 章的自适应时，字号也要按缩放比例算（项目里是 `clamp(12/cssScale, 13, 30)` 这种写法）。

# 第 9 章 · 球撞球

**本章目标**：判断两颗球是否碰上；碰上后把速度按物理规律"传"过去；同时把两颗球推开，避免粘在一起。

**开始之前**：第 8 章 —— 球会动了，速度是 `vx / vy`。

这一章有一点数学，但用的全是高中向量，而且公式总共四行。**看不懂公式就先看"生活版解释"，代码照抄也能跑对。**

---

## 1. 先判断"碰上没有"

两颗球半径都是 14，所以**球心距离小于 28 就是碰上了**（等于 28 是刚好贴着）。

```js
const BALL_R = 14;
const minD = BALL_R * 2;      // 28

const dx = b.x - a.x;
const dy = b.y - a.y;
const d2 = dx * dx + dy * dy;         // 距离的平方
if (d2 >= minD * minD) return;        // 没碰上
```

**为什么用平方比较？** 因为算距离要开根号（`Math.sqrt`），开根号很贵。既然只是比较"小于 28"，那"平方小于 784"完全等价，还快。

（要真正用到距离值时才开根号，下面马上就用到。）

---

## 2. 生活版解释：正撞与斜撞

- **正着撞**（两颗球心连线正好在运动方向上）：动的球把速度几乎全交给静止的球，自己停下。就像牛顿摆。
- **斜着撞**（擦着边）：只把"沿连线方向的那一份速度"传过去，静止球沿连线方向跑，母球偏向另一侧继续走。这就是台球里的"分球"。

所以关键只有一个：**连线方向**。

```
        b
         \
          \   ← 连线方向（法线）
           \
            a →→ 运动方向
```

把速度拆成"沿连线"和"垂直于连线"两份，**只交换沿连线的那一份**。

---

## 3. 法线：连线的单位方向

```js
const d = Math.sqrt(d2);     // 真实距离
const nx = dx / d;           // 连线方向，长度 1
const ny = dy / d;
```

`nx, ny` 是"从 a 指向 b"的单位向量，游戏里管它叫**法线**（碰撞法线）。长度是 1 很关键：这样点乘出来的就是"速度在连线方向上的分量"。

```js
// 相对速度在连线方向上的投影
const rvn = (b.vx - a.vx) * nx + (b.vy - a.vy) * ny;
```

这就是**点乘**：两个向量对应相乘再相加。结果的物理意义是"两颗球正在以多快的速度互相靠近"。

- `rvn < 0`：正在靠近（要处理碰撞）
- `rvn > 0`：正在分开（已经碰过了，别再推一把，否则球会"粘着反复弹"）

---

## 4. 冲量公式（就四行）

等质量、弹性系数 `e` 的两球碰撞，代码是固定的：

```js
const BALL_RESTI = 0.96;                 // 弹性，1 = 完全弹性，0.96 略损失
const imp = -(1 + BALL_RESTI) * rvn * 0.5;

a.vx -= imp * nx;
a.vy -= imp * ny;
b.vx += imp * nx;
b.vy += imp * ny;
```

- `-(1+e) * rvn` 是标准公式里"交换的冲量大小"，`* 0.5` 是因为两球等质量、各分一半
- a 减、b 加，方向相反 → 动量守恒
- `e = 1` 时正撞：动的球完全停住，静止球拿走全部速度（牛顿摆）
- `e = 0.96` 时留一点点在母球身上，看起来更自然（真球也不是绝对弹性）

**`js/physics.js` 的 `collideBalls` 就是这几行，没有更多。**

---

## 5. 还得把它们推开

只改速度不够。因为浮点误差，两颗球可能**一直处在"距离 27.999"的状态**——每帧都判定碰撞、每帧都弹一次，结果它们粘在一起抖。

所以碰撞时先按重叠量把两颗球"各退一半"：

```js
const overlap = minD - d;         // 叠了多深
a.x -= nx * overlap * 0.5;
a.y -= ny * overlap * 0.5;
b.x += nx * overlap * 0.5;
b.y += ny * overlap * 0.5;
```

推完再算速度。这样下一帧它们的距离正好是 28，不会反复触发。

---

## 6. 一个额外收获：记录"母球第一下碰到谁"

规则判定要用它（比如"必须先碰自己的球组"）：

```js
if (state.shot && state.shot.firstHit === null && (a.id === 0 || b.id === 0)) {
  state.shot.firstHit = (a.id === 0) ? b.id : a.id;
}
```

每杆开始时把 `firstHit` 设成 `null`，碰撞里第一次命中就记下来，之后不再改。第 14 章讲规则时会用到。

## 7. 合起来（接第 8 章的代码）

```js
function collideBalls(a, b) {
  const dx = b.x - a.x, dy = b.y - a.y;
  const d2 = dx * dx + dy * dy;
  const minD = BALL_R * 2;
  if (d2 >= minD * minD || d2 < 1e-6) return;   // 没碰上 / 完全重合（避免除以 0）

  const d = Math.sqrt(d2);
  const nx = dx / d, ny = dy / d;

  // 1) 先分离
  const overlap = minD - d;
  a.x -= nx * overlap * 0.5;
  a.y -= ny * overlap * 0.5;
  b.x += nx * overlap * 0.5;
  b.y += ny * overlap * 0.5;

  // 2) 记录第一颗被母球碰到的球
  if (state.shot && state.shot.firstHit === null && (a.id === 0 || b.id === 0)) {
    state.shot.firstHit = (a.id === 0) ? b.id : a.id;
  }

  // 3) 正在分离就别再推
  const rvn = (b.vx - a.vx) * nx + (b.vy - a.vy) * ny;
  if (rvn > 0) return;

  // 4) 交换沿连线的速度
  const imp = -(1 + BALL_RESTI) * rvn * 0.5;
  a.vx -= imp * nx;  a.vy -= imp * ny;
  b.vx += imp * nx;  b.vy += imp * ny;
}
```

主循环里对**每一对球**都跑一次：

```js
for (let i = 0; i < balls.length; i++) {
  for (let j = i + 1; j < balls.length; j++) {
    collideBalls(balls[i], balls[j]);
  }
}
```

`j` 从 `i + 1` 开始，是为了不重复处理同一对（也不让球和自己碰）。

**16 颗球就是 120 对，每步跑 240 次/秒 → 每秒 2.8 万次判断，浏览器完全扛得住。**

---

## 8. 坑

1. **`d2 < 1e-6` 忘了判断。** 两颗球心完全重合时 `d = 0`，`dx / d = Infinity`，整个数组变 `NaN`，画面直接消失。
2. **先算速度再分离。** 顺序反了会有"球被弹开又吸回去"的抖动。
3. **`rvn > 0` 不做拦截。** 已经弹开的球继续被施加冲量，会看到两颗球疯狂对撞。
4. **`imp` 里的 `0.5` 漏了。** 速度变成两倍，球会"越撞越快"，能量凭空增加。

# 从零做一款能玩的台球游戏

这是一套"边学边做"的教程：你从一个空文件夹开始，最后会得到一款能在浏览器里双击打开、支持人机对战和本地双人的八球台球游戏。

**这门教程假定你从没写过 JavaScript。** 会打字、会用浏览器、知道怎么新建文件夹就够了。

---

## 最后你会做出什么

- 一张画在浏览器里的台球桌，16 颗球，母球能瞄准、能拖力度
- 真正的物理：球会滚动、减速、互撞、撞库、落袋
- 完整规则：中式八球 / 美式八球、分球组、犯规、手中球、黑八指定袋
- 三档难度的电脑对手，甚至让两台电脑互相打给你看
- 一杆回放、音效、本局计时、本地战绩（刷新不丢）
- 手机横屏全屏可玩

这些功能在仓库里一共约 3100 行代码（不含注释约 2200 行）。**我们不追求一次写完 3100 行，而是每一章只往前挪一小步，每步都能看见效果。**

---

## 怎么读这套教程

每一章都按同一个顺序展开，你照着走就不会迷路：

1. **本章目标** —— 学完你能看到什么
2. **开始之前** —— 需要先会什么（一般就是"上一章的内容"）
3. **讲清楚这件事** —— 用生活化的比喻解释概念，不堆术语
4. **最小代码** —— 一段能直接跑起来的代码，几十行，不是整份项目
5. **在本项目里对应哪** —— 打开仓库的哪个文件、哪个函数去看真实实现
6. **容易踩的坑** —— 这个问题我们实际踩过，以及怎么验证改对了
7. **动手练习** —— 三到五道小题，做完了再看下一章

**每章建议留 30–60 分钟。** 22 章别指望一口气读完，一天一章，三周能走完，而且记得住。

### 关于抄代码

手敲一遍，不要复制粘贴。复制粘贴能省 5 分钟，但你不会发现自己漏了一个分号、或者把中文标点混进去了——而这两种正是新手 80% 的报错来源。

## 需要准备什么

| 东西 | 说明 |
| --- | --- |
| 浏览器 | 推荐 Chrome，本教程所有截图和验证都是它。Edge 也行 |
| 编辑器 | VS Code（免费）最舒服；实在不想装，系统自带的记事本也能写 |

## 本项目文件地图

教程里说"去项目里看真实实现"时，对照这张表：

```
my-pool/
├── index.html          ← 页面骨架：页头、球号条、画布、右侧面板
├── css/
│   ├── base.css        ← 颜色变量、按钮、页头基础样式
│   ├── layout.css      ← 整体布局、画布、页头小按钮
│   ├── rack.css        ← 台面上方球号条、本局计时
│   ├── panel.css       ← 右侧设置面板、状态卡、力度条
│   ├── overlay.css     ← 弹窗、提示条
│   └── responsive.css  ← 窄屏 / 手机横屏两套布局
└── js/
    ├── config.js       ← 所有常量：尺寸、袋口、物理参数、颜色
    ├── util.js         ← 小工具：clamp、dist、颜色明暗
    ├── state.js        ← 全局状态：球、回合、阶段、计时
    ├── balls.js        ← 造球、摆球、手中球可用性
    ├── canvas.js       ← 拿画布、处理清晰度
    ├── render.js       ← 画台面、画球、画光晕、画手中球提示
    ├── aim.js          ← 瞄准方向、辅助线、力度药丸
    ├── physics.js      ← 物理：摩擦、碰撞、库边、落袋
    ├── input.js        ← 鼠标/触摸
    ├── rules.js        ← 一杆的生命周期、两套规则、犯规
    ├── score.js        ← 胜负结算、战绩、弹窗
    ├── ai.js           ← 电脑对手
    ├── sound.js        ← 音效（代码合成的，没有音频文件）
    ├── replay.js       ← 上一杆回放
    ├── hud.js          ← 界面数字：状态、力度、计时、提示条
    ├── loop.js         ← 主循环：每帧推进物理 + 重画
    └── main.js         ← 启动：按顺序把上面这些接起来
```

**注意这个分层思路**：常量、状态、画面、物理、规则、界面各自一个文件。你现在可能看不懂，但记住一句话——**"画"和"算"分开，改外观不会改坏物理**。第 4 章会细讲为什么这么分。

## 卡住了怎么办

1. **页面一片空白** → 按 `F12`，看 Console 里有没有红字。红字第一行往往就是原因（比如 `xxx is not defined` 意思是"这个名字没定义"）。
2. **改了代码没反应** → 90% 是文件没保存，或者浏览器没刷新（`Ctrl + R`）。
3. **报错里有"中文引号""中文括号"** → 代码里的标点必须是英文半角，`“”` 要换成 `""`，`；` 换成 `;`。
4. 还是不行，就**回退到上一章能跑的样子，再一小步一小步加**。我们后面 21 章里会反复用这一招。

## 三条约定

- **逻辑坐标**：台面固定按 `1120 × 620` 这个"虚拟尺寸"计算，显示多大由屏幕决定。第 7 章解释。
- **常量用大写**：`BALL_R`（球半径）、`MAX_SPEED`（满力球速）。看到大写就知道"这个数不会变"。
- **注释写"为什么"**，不写"是什么"：`// 袋口收紧一档，中式比美式难进` 比 `// 设置袋口半径` 有用。

准备好了就从[第 1 章](01-先跑起来.md)开始。

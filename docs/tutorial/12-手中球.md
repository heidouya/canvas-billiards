# 第 12 章 · 手中球

**本章目标**：实现"犯规后可以摆母球"；让同一个拖拽动作在摆球和瞄准两种模式下各干各的事；搞清楚 `pointercancel` 为什么不能当成松手。

**开始之前**：第 11 章 —— 已经会拖拽瞄准、松手出杆。

---

## 1. 什么是"手中球"

真实规则里，犯规之后对方可以**把母球拿起来，放到台面上合适的位置**，然后再打。这就是"手中球"（ball in hand）。

开球前也是手中球：母球要先摆在开球区里。

所以要有两个拖拽模式：

| 模式 | 按下位置 | 拖动效果 | 松手效果 |
| --- | --- | --- | --- |
| `aim`（瞄准） | 台面任意位置 | 改方向、改力度 | 力度够就出杆 |
| `place`（摆球） | **必须按在母球上** | 母球跟着走 | 落位，退出手中球 |

---

## 2. 怎么判断"他要摆球还是瞄准"

判据就是"按下的那一下，是不是按在母球上"：

```js
const cue = cueBall();       // state.balls[0]
if (state.ballInHand && cue && dist(p.x, p.y, cue.x, cue.y) < BALL_R * 2.6) {
  state.dragMode = 'place';
  state.placeOrigin = { x: cue.x, y: cue.y };   // 记住原位，摆不成要退回去
  return;
}
state.dragMode = 'aim';
state.aiming = true;
updateAimFromPointer(p);
```

`BALL_R * 2.6 ≈ 36`：手指的接触面比鼠标大，判定半径给宽一点，否则玩家老是"按不准"，摆球要试好几次。

**这个 2.6 也是调出来的**：太小（比如 1.5 倍）手机上根本按不到；太大（比如 4 倍）玩家想瞄准时稍微按偏一点就被当成摆球，感觉"打不了球"。

---

## 3. 摆球时的约束

母球不能摆在台面外，也不能压在别的球上。

```js
// 左右边界：开球阶段只能放左半边（开球线以左）；犯规后的自由球中式可放全台
const maxX = state.ballInHand ? cueZoneRight() : TABLE.x + TABLE.w - BALL_R;
const tx = clamp(p.x, TABLE.x + BALL_R, maxX);
const ty = clamp(p.y, TABLE.y + BALL_R, TABLE.y + TABLE.h - BALL_R);

if (cueFits(tx, ty)) {       // 这个位置有没有压到别的球
  cue.x = tx;
  cue.y = ty;
}
```

`cueZoneRight()` 是规则决定的：

```js
function cueZoneRight() {
  if (!state.breakDone) return HEAD_X;                 // 还没开球：开球线以左
  return state.ruleSet === 'cn' ? TABLE.x + TABLE.w    // 中式：全台
                                : HEAD_X;              // 美式：还是开球区
}
```

`cueFits` 就是遍历其他球，检查距离不小于 28：

```js
function cueFits(x, y) {
  return state.balls.every(function (b) {
    if (!b.active || b.id === 0) return true;   // 跳过自己和落袋球
    return dist(x, y, b.x, b.y) >= BALL_R * 2;
  });
}
```

不合法就不让它移动（`if (cueFits)` 才赋值）——这样母球会"卡"在最后一个合法位置上，玩家能感觉到边界。

## 4. 松手：摆上去，退出手中球

```js
if (wasPlace) {
  const cue = cueBall();
  if (cue && !cueFits(cue.x, cue.y) && state.placeOrigin) {
    cue.x = state.placeOrigin.x;     // 落点不合法 → 回原位
    cue.y = state.placeOrigin.y;
  }
  if (state.moved) {                 // 真的拖动过才算摆完
    state.ballInHand = false;
    state.placeOrigin = null;
  }
  state.power = 0;
  return;
}
```

两个细节：

- **`state.moved`**：只点一下不拖，不算摆球（否则玩家想瞄准时按一下球，就会白白浪费手中球机会）
- **回原位**：位置不合法又松手了，退回拖动前的位置，手中球状态保留

---

## 5. 这一章最坑的 bug：`pointercancel`

上线后玩家反馈："**有时候手中球拖到一半，我还没松手，它自己就放下了。**"

原因：我们一开始把 `pointercancel` 直接绑成了 `onPointerUp`：

```js
canvas.addEventListener('pointercancel', onPointerUp);   // ❌ 错
```

`pointercancel` 表示"系统把这个指针事件流抢走了"——切到别的 App、系统手势（比如从屏幕边缘滑动返回）、指针捕获丢失、窗口失焦，都会触发。

它**不是用户松手**。当成松手处理，就会在用户还按着的时候提交摆位——正是那个 bug。

正确做法：把这次拖拽**作废**：

```js
function abortDrag() {
  if (activePointer === null) return;
  activePointer = null;

  const wasPlace = state.dragMode === 'place';
  const wasAim = state.aiming;
  state.dragMode = null;
  state.moved = false;

  if (wasPlace) {
    const cue = cueBall();
    if (cue && state.placeOrigin) {
      cue.x = state.placeOrigin.x;       // 母球退回原位
      cue.y = state.placeOrigin.y;
    }
    state.placeOrigin = null;            // 手中球状态保留，可以重新拖
  }
  if (wasAim) {
    state.aiming = false;
    state.power = 0;                     // 瞄准也取消，收杆
  }
  updateStatus();
}

canvas.addEventListener('pointercancel', abortDrag);
window.addEventListener('blur', abortDrag);   // 切窗口同样作废
```

**核心差别**：

- `pointerup` = 用户主动松手 → **提交**（摆位生效、出杆）
- `pointercancel` / `blur` = 外界打断 → **回滚**（什么都不提交，状态回到拖拽前）

这一条在真机上非常容易复现：全屏状态下从屏幕边缘划一下、或者来通知切出去。

---

## 6. 坑

1. **`pointercancel` 绑成 `pointerup`。** 就是上面那个 bug。
2. **摆完没清 `ballInHand`。** 玩家摆完球再想瞄准时，按在母球附近又被当成摆球，体感是"这局我打不了球了"。
3. **`placeOrigin` 没存。** 落点不合法时无法回原位，球会留在库边或压在别的球上。
4. **约束只做了 X 没做 Y。** 球能被拖出上下边界，飞出台面。

---

## 7. 练习

1. 开球状态下摆母球，确认只能放在开球线以左。
2. 犯规后（自由球）在中式里试着放到右半边，应该能放。
3. 在母球上按下、拖一点点松开，观察是否立刻退出手中球。
4. 全屏后从屏幕边缘滑动（模拟系统手势），确认母球回到原位、手中球还在（这就是 `abortDrag` 的效果）。

# 第 10 章 · 撞库与落袋

**本章目标**：球撞到木框会反弹；球滚进袋口就从台上消失；明白为什么库边要拆成 6 段而不是 4 条边。

**开始之前**：第 8、9 章 —— 球会动、会互撞。

---

## 1. 库边不是"四条边"，是"六段线"

台面四个角有袋口，每条边的中间也有袋口（中袋）。如果按"四条完整的边"做碰撞，球走到袋口位置会被边挡住，进不去。

所以把库边拆成**六段线段**，袋口处留空：

```
        ┌───┐   ┌───┐   ┌───┐
        │   │   │   │   │   │     ← 上边：两段，中间留中袋
        └───┘   └───┘   └───┘
  左库两段？不，左库是整整一段（竖向），只有上下两端让给角袋
```

项目 `js/config.js` 里：

```js
const RAIL_GAP = 34;   // 袋口处留空 34

const RAIL_SEGS = [
  { x1: 94,  y1: 60,  x2: 526, y2: 60  },   // 上边左段
  { x1: 594, y1: 60,  x2: 1026, y2: 60 },   // 上边右段
  { x1: 94,  y1: 560, x2: 526, y2: 560 },   // 下边左段
  { x1: 594, y1: 560, x2: 1026, y2: 560 },  // 下边右段
  { x1: 60,  y1: 94,  x2: 60,  y2: 526 },   // 左库
  { x1: 1060, y1: 94, x2: 1060, y2: 526 }   // 右库
];
```

（实际代码里是 `TABLE.x + RAIL_GAP` 这样算出来的，这里直接写成数字方便你看。）

**好处**：线段端点天然形成"袋角"。球擦着袋角落进去时会被端点弹一下——这就是真实台球里"袋口弹库"的手感，白送的。

## 2. 球到线段的距离：最近点

球是圆，线段是斜的，所以不能只看端点。要找**线段上离球心最近的那个点**：

```js
function collideRails(b) {
  RAIL_SEGS.forEach(function (s) {
    const dx = s.x2 - s.x1, dy = s.y2 - s.y1;
    const segLen2 = dx * dx + dy * dy;

    // 球心投影到线段上的参数 t，夹在 0~1 之间（防止越出端点）
    const t = clamp(
      ((b.x - s.x1) * dx + (b.y - s.y1) * dy) / segLen2,
      0, 1
    );

    const px = s.x1 + dx * t;     // 线段上的最近点
    const py = s.y1 + dy * t;

    const ox = b.x - px, oy = b.y - py;
    const d = Math.hypot(ox, oy);
    if (d >= BALL_R || d < 1e-6) return;   // 没碰到

    const nx = ox / d, ny = oy / d;        // 从库边指向球心的法线

    // 1) 推出去，别嵌在库里
    b.x = px + nx * BALL_R;
    b.y = py + ny * BALL_R;

    // 2) 只在"还在往里撞"时反弹
    const vn = b.vx * nx + b.vy * ny;
    if (vn < 0) {
      b.vx -= (1 + CUSHION_RESTI) * vn * nx;
      b.vy -= (1 + CUSHION_RESTI) * vn * ny;
    }
  });
}
```

`clamp(..., 0, 1)` 这一步是精髓：**球在线段"正外侧"时 t 落在 0~1 之间；球跑到线段延长线上时，t 被夹到端点**，于是最近点变成端点——自然就有了"角袋弹库"。

### 反弹为什么是这个公式

```js
const vn = b.vx * nx + b.vy * ny;    // 速度在法线方向上的分量
if (vn < 0) {                        // 负 = 还在往里，需要反弹
  b.vx -= (1 + CUSHION_RESTI) * vn * nx;
  b.vy -= (1 + CUSHION_RESTI) * vn * ny;
}
```

在法线方向的速度分量"翻转并乘以弹性系数"，切向分量**完全不动**（球贴着库走的那部分速度不该丢，否则球会突然减速）。

`CUSHION_RESTI = 0.84`：撞库损失 16% 速度。这个数调过很多次，0.9 以上显得"弹得太活"，0.75 以下又"发闷"。

## 3. 落袋判定

袋口视觉半径 32，但**判定半径只有 26**：

```js
const POCKET_R_US = 32;     // 视觉半径：画出来的黑圆多大
const CAPTURE_R_US = 26;    // 判定半径：球心进到这个范围才算落袋
```

为什么要小 6？因为如果判定半径等于视觉半径，球"擦着袋口边"就被吞了，看起来像穿模。判定小一点，球得真正"进洞"才算。

中式规则袋口更紧：

```js
const POCKET_R_CN = 29;
const CAPTURE_R_CN = 23;
```

```js
function checkPocket(b) {
  for (let i = 0; i < POCKETS.length; i++) {
    const p = POCKETS[i];
    if (Math.hypot(b.x - p.x, b.y - p.y) < CAPTURE_R) {
      pocketBall(b, i);
      return;
    }
  }
}
```

`pocketBall` 只做四件事：

```js
function pocketBall(b, pocketIdx) {
  b.active = false;        // 1) 从台上消失（画的时候跳过）
  b.vx = 0; b.vy = 0;      // 2) 速度清零
  sfxPocket(b.id === 0);   // 3) 放个音效（母球落袋声音不同）
  state.shot.potted.push({ id: b.id, pocket: pocketIdx });  // 4) 记账，规则要用
}
```

**`b.active = false` 而不是把球从数组里删掉** —— 因为我们要保留它的编号信息（"这杆进了 3 号和 7 号"），只是不再画、不再碰撞。

## 4. 兜底：万一球飞出去了

高速球 + 极端角度，理论上可能一帧穿过袋口飞出台面。加一条保险：

```js
if (b.x < TABLE.x - 34 || b.x > TABLE.x + TABLE.w + 34 ||
    b.y < TABLE.y - 34 || b.y > TABLE.y + TABLE.h + 34) {
  // 找最近的袋口，按落袋处理
}
```

宁可"莫名其妙进袋"，也不能让球跑到屏幕外找不回来。

## 5. 坑

1. **先反弹再推出。** 顺序反了会看到球被弹进库内、下一帧再弹出来，反复抖。
2. **反弹不判断 `vn < 0`。** 球静止贴库时每帧都被"弹"一下，会自己跑起来。
3. **判定半径等于视觉半径。** 球擦袋就消失，玩家会骂你。
4. **把 `active` 设成 false 却没跳过绘制。** 落袋的球还在原地躺着。

## 6. 练习

1. 让母球斜着撞上库，观察入射角约等于反射角。
2. 把 `CUSHION_RESTI` 改成 `1`（零损失），球会在库里弹很久都不停。
3. 把 `CAPTURE_R` 改成 `40`（比袋口还大），感受"球擦一下就掉"的离谱。
4. 打印每颗球落袋时的袋口编号，确认角袋/中袋判定正确。

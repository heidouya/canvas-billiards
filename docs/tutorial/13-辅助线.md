# 第 13 章 · 辅助线

**本章目标**：从母球沿瞄准方向发一条射线，算出它先撞到哪颗球（或哪段库边），把结果画出来；做"完整 / 短线 / 关闭"三档。

**开始之前**：第 9、10 章（知道球与球的半径关系、库边是线段）、第 11 章（有 `aimDir`）。

---

## 1. 先想清楚要算什么

按住拖拽时，母球沿 `aimDir` 方向前进。我们要回答一个问题：

> 沿着这条射线走，**第一个**碰到的是什么？在哪个点？

数学上这叫**射线与圆求交**、**射线与线段求交**。两种都要会。

---

## 2. 射线 vs 球（圆）

一颗球被母球撞到时，母球球心能走到最近的位置是"两球相切"——所以把目标球半径放大成 `2R = 28` 来算交点。

```
             目标球（半径 R）
                ●
              ╱   ╲
   母球 ────╱─────╲────→ 射线
          ╱ 交点
```

```js
const R2 = BALL_R * 2;      // 28，放大后的目标半径

function rayHitBall(px, py, dx, dy, b) {
  const ox = b.x - px, oy = b.y - py;

  // 球心在射线方向上的投影长度
  const proj = ox * dx + oy * dy;
  if (proj <= 0) return Infinity;             // 在身后，不算

  // 球心到射线的垂直距离的平方
  const perp2 = ox * ox + oy * oy - proj * proj;
  if (perp2 > R2 * R2) return Infinity;       // 射线擦不到这个圆

  // 交点距离 = 投影 - 圆内的那一截
  return proj - Math.sqrt(R2 * R2 - perp2);
}
```

`proj` 和 `perp2` 是这行的核心：把"球心相对母球的位置"拆成"沿射线方向"和"垂直射线方向"两部分。垂直距离小于 28 才可能撞上。

返回值是"沿射线要走多远才碰到"，`Infinity` 表示碰不到。

---

## 3. 射线 vs 线段（库边）

第 10 章我们算的是"球心到线段的距离"，这里要算的是"两条线在哪相交"。

```js
function rayHitSeg(px, py, dx, dy, s) {
  const ex = s.x2 - s.x1, ey = s.y2 - s.y1;
  const det = ex * dy - dx * ey;
  if (Math.abs(det) < 1e-9) return Infinity;      // 平行

  const t = (ex * (s.y1 - py) - ey * (s.x1 - px)) / det;   // 沿射线走多远
  const u = (dx * (s.y1 - py) - dy * (s.x1 - px)) / det;   // 落在线段上的位置 0~1

  if (t <= 0 || u < 0 || u > 1) return Infinity;  // 在身后 / 不在这一截上
  return t;
}
```

`u` 落在 0~1 之外，说明交点在那段库边的延长线上（比如已经过了袋口），不算。

**这两个公式不用背。** 记住它们回答的问题就行："沿射线走多远会碰到？"——想换实现时用向量解法重推一遍也行。

## 4. 取最近的

```js
function predictHit(px, py, dir) {
  let best = Infinity;
  let hitBall = null;

  state.balls.forEach(function (b) {
    if (!b.active || b.id === 0) return;
    const t = rayHitBall(px, py, dir.x, dir.y, b);
    if (t < best) { best = t; hitBall = b; }
  });

  RAIL_SEGS.forEach(function (s) {
    const t = rayHitSeg(px, py, dir.x, dir.y, s);
    if (t < best) { best = t; hitBall = null; }
  });

  return { dist: best, ball: hitBall };
}
```

先算所有球，再算所有库边，谁最近听谁的。`best` 初始值是 `Infinity`，任何有限值都会覆盖它。

## 5. 画出来：三档

```js
const aimMode = 'full';   // 'full' | 'short' | 'off'
const AIM_SHORT_LEN = 132;
```

| 档位 | 画什么 | 为什么这么设计 |
| --- | --- | --- |
| `完整` | 从母球画到碰撞点 + 起点光点 + 终点箭头 | 新手需要"能不能打到"的确认 |
| `短线` | 只画出发方向 132 逻辑像素，末端渐隐 | 老手只要方向，不想被"结果"剧透 |
| `关闭` | 什么都不画，只靠球杆 | 最硬核，也最安静 |

```js
function drawAimLine(ctx, cue, dir, hit) {
  if (aimMode === 'off') return;

  const len = aimMode === 'short'
    ? AIM_SHORT_LEN
    : Math.min(hit.dist, 4000);     // 完整档画到碰撞点

  const x2 = cue.x + dir.x * len;
  const y2 = cue.y + dir.y * len;

  ctx.save();
  ctx.setLineDash([10, 8]);          // 虚线
  ctx.strokeStyle = 'rgba(255,255,255,.55)';
  ctx.lineWidth = 2;
  ctx.beginPath();
  ctx.moveTo(cue.x + dir.x * BALL_R, cue.y + dir.y * BALL_R);   // 从球边起笔
  ctx.lineTo(x2, y2);
  ctx.stroke();
  ctx.restore();
}
```

`setLineDash([10, 8])` 是"画 10 停 8"，做虚线。`restore()` 一定要有，否则后面所有线都变虚线。

### 一个容易忽略的细节：只在"该显示"的时候显示

辅助线不该一直挂着。项目里它只在**正在拖拽**时出现：

```js
const showAim = state.aiming || state.dragMode === 'place';
```

空闲时台面干干净净，只留母球一圈呼吸光——这是用户明确要求的"别在台面上留一条旧方向"。

## 6. 一个特殊场景：摆球时线指向谁

手中球拖动母球摆位时，母球位置在变，"瞄准方向"其实还没定。但玩家需要一个反馈："我这颗球摆在这儿，能打到什么"。

所以摆位时改成**自动指向最近的可打球**：

```js
function nearestPlayableDir(cue) {
  let best = null, bestD = Infinity;
  state.balls.forEach(function (b) {
    if (!b.active || b.id === 0) return;
    if (!isPlayable(b)) return;        // 不是本方目标球就跳过
    const d = dist(cue.x, cue.y, b.x, b.y);
    if (d < bestD) { bestD = d; best = b; }
  });
  if (!best) return { x: 1, y: 0 };
  const dx = best.x - cue.x, dy = best.y - cue.y;
  const d = Math.hypot(dx, dy) || 1;
  return { x: dx / d, y: dy / d };     // 指向最近那颗
}
```

**这条是修 bug 修出来的**：早期版本摆球时线会指向"上次瞄准的方向"，玩家把母球拖到台面另一侧，线就指向一片空白，看着像坏了。改指向最近的球后，"乱跑"的现象没了。

---

## 7. 坑

1. **从球心起笔。** 线会穿过母球一半，很难看。从 `cue.x + dir.x * BALL_R` 开始。
2. **只算球不算库边。** 空台时线画到无穷远，穿过木框。
3. **`dist` 为 `Infinity` 时直接乘。** `Infinity * 0` 是 `NaN`，画面消失。画之前先判有限值。
4. **虚线之后忘了 `restore`。** 全台面都变虚线，包括球。

## 8. 练习

1. 空台时拖动，确认线停在库边上而不是穿过去。
2. 把 `AIM_SHORT_LEN` 改成 `60`，短线档更短。
3. 加一个"预测碰撞点小圈"：在 `hit` 位置画一个空心圆。
4. 关掉辅助线（`aimMode = 'off'`），确认台面只剩球杆——这是"关闭"档的观感。
